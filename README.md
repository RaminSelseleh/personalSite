# raminsel.github.io

My personal site: cloud and AI work, experience, side projects, and what I do off the clock.

Live at **https://raminsel.github.io**

## Structure

```
index.html          page content
css/styles.css      design tokens, layout, light/dark themes
js/main.js          copy-email button
assets/favicon.svg  site icon
```

Plain HTML, CSS, and JavaScript. No build step; GitHub Pages serves it as is.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
